# `/ag-artifacts` — Delegation Artifacts, Screenshots & Log Viewer

Inspect browser screenshots, `report.md`, and redacted `agy-cli.log` tails generated by Antigravity delegations via `list_ag_artifacts`.

## Execution Procedure

1. Parse optional `taskId`, `--lines <n>` (default `40`), `--no-report`, `--no-logs` from `$ARGUMENTS`.
2. Call `list_ag_artifacts({ taskId, includeReport: !noReport, includeLogTail: !noLogs, logTailLines })`.
3. Display:
   - Task summary (`taskId`, `taskTitle`, `taskStatus`)
   - Artifact table: `Kind` (`screenshot` / `log` / `report` / `json` / `other`), `Relative Path`, `Size`, `Modified`
   - `reportMarkdown` preview (if present) and redacted `logTail` (if requested)
   - Recent `availableTasks` with artifact counts so the user can jump to any archived task.
